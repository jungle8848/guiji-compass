# 硅基罗盘 · 钉钉聚合一站式工作台

面向中层管理者的钉钉跨源聚合工作台：把散在文档、OA 审批、会议听记、待办、多维表、日程里的团队真实信号，聚合成一屏可读、**每条可溯源**的进展与协作视图。

千问办公全国大赛参赛作品。当前为**纯 mock 数据**（虚构企业「职场有AI硅蜜」），不连接任何真实企业数据。

## 四条产品主线

| 代号 | 名称 | 说明 |
|---|---|---|
| 周知 | 团队进展驾驶舱 | 六类信号一屏归拢 + 来源核验三态（核验中 / 已核验 / 存疑待纠错） |
| 同频 | 跨源进展与协作舱 | 一周会议泳道图，撞车高亮 + 可合并建议 + 未共享灰位 |
| 流转 | 团队审批动态全景 | OA 审批状态、卡点、时效、催办 |
| 笔耕 | 团队文档创作与更新 | 文档新增/上传/改版时间线与版本回溯 |

外加工具型页面：周报（草稿编辑 + 存文档/发邮件）、设置（数据源与权限、知情说明）。

## 快速开始

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 生产构建（tsc -b && vite build）
```

技术栈：Vite + React + TypeScript + Ant Design，主题走 editorial-motion 暖纸风（纸底 #F5F0EB、鼠尾草绿 #5E6E54、赭石 #A8621F）。

## 协作约定

- 分支：`main` 保持可跑；功能分支 `feat/<名字>`（如 `feat/ui-polish`、`feat/mock-refit`），改完提 PR 合回 `main`。
- 不要提交 `node_modules/`、`dist/`（已在 .gitignore）。
- 提交前本地跑一次 `npm run build`，保证不引入 TS 报错。
- 一次 PR 只做一件事，方便快速合并（时间紧，别攒大包）。

## 权限边界（重要，请先读）

- **前端迭代不需要任何钉钉登录权限**——数据全是 mock，clone 下来就能改、能跑、能调试。
- 真实数据链路由项目维护者用钉钉 CLI（`dws`）在其本人权限范围内探测，产出结果以**数据文件**形式提交进来，协作者不接触任何凭据。
- 严禁共享或提交：token、refresh token、appSecret、`~/.dws` 目录、任何 `.env`。
- 若协作者需要调试真实链路，请用自己的钉钉账号登录自己的环境，不要共用他人登录态。
